Game Commands

Available Commands:

  • create a [type] game - Types: platformer, shooter, maze
  • add player at X Y [colored COLOR] - Add player character
  • add platform at X Y width W height H - Add platform
  • add enemy at X Y [colored COLOR] - Add enemy
  • add coin at X Y [colored COLOR] - Add collectible
  • add obstacle at X Y width W height H - Add obstacle
  • set gravity to VALUE - Set gravity (0-2)
  • set background to COLOR - Set background color
